# Part V: Non-Functional Requirements (NFRs)

## 5.1. Security & Privacy

### Data Protection
- **Encryption in Transit:** All data transmitted via HTTPS/TLS 1.3.
- **Encryption at Rest:** Convex provides encryption at rest for all database records.
- **File Security:** Uploaded documents stored securely in Convex File Storage with controlled access.

### Authentication
- **Identity Provider:** Clerk handles all authentication with industry-standard security.
- **Session Management:** JWT-based sessions with automatic rotation.
- **Protected Routes:** All private application routes require valid Clerk session.
- **Webhook Verification:** Clerk webhooks verified using SVIX signature validation.

### Authorization

| Role | Capabilities |
|------|--------------|
| **Guest** | View public projects, landing page only |
| **User (Basic)** | View projects, apply to teams, follow projects |
| **Entrepreneur** | Create projects, manage workspaces, post bounties |
| **Investor** | Soft circle commitments, data room access, matchmaking |
| **Admin** | User moderation, certification verification, feature flags |

### Row-Level Security
- Users can only view their own private profile data.
- Project owners control who can access their data rooms.
- Workspace members only access their assigned workspaces.
- Soft circle investor identities hidden from public view.

### Data Room Security
- **Access Control:** Explicit grant required for each user.
- **NDA Workflow:** Optional NDA signature before document access.
- **Audit Trail:** All document views logged with timestamp and user.
- **Access Revocation:** Immediate effect when access is revoked.
- **Expiration:** Optional automatic access expiration.

### Privacy Controls
- **Private Identity:** Real names and emails hidden by default.
- **Public Persona:** Users control public profile visibility.
- **Professional Bio:** Public-facing information user-controlled.
- **Certification Display:** Verified credentials visible on profile.

## 5.2. Performance & Scalability

### Real-time Latency
- **Target:** Message delivery and notifications < 100ms.
- **Technology:** Convex WebSocket-based subscriptions.
- **Optimistic Updates:** UI updates immediately, server confirms async.

### Database Performance
- **Indexing Strategy:** All frequently-queried fields indexed.
- **Compound Indexes:** Multi-field indexes for complex filters (industry + status).
- **Full-Text Search:** Username search via Convex search index.
- **Pagination:** Large result sets paginated to prevent memory issues.

### Key Indexes

| Table | Index | Purpose |
|-------|-------|---------|
| `users` | `by_clerk_id` | Auth lookup |
| `users` | `by_role` | Role-based filtering |
| `projects` | `by_status` | Published project listing |
| `projects` | `by_industry_status` | Discovery filtering |
| `projects` | `by_traction_score` | Score-based sorting |
| `applications` | `by_project_status` | Application management |
| `conversations` | `by_workspace` | Workspace chat lookup |
| `messages` | `by_conversation` | Message retrieval |
| `dataRoomAccess` | `by_data_room_user` | Access verification |

### Asset Optimization
- **Images:** Optimized for web display, lazy loading.
- **Documents:** PDF pitch decks served via CDN.
- **File Storage:** Convex handles caching and delivery optimization.

### Scheduled Job Performance
- **Daily Analytics:** Processes all projects sequentially to avoid rate limits.
- **Score Recalculation:** Batched processing with scheduler delays.
- **Error Handling:** Failed jobs logged, manual retry available.

## 5.7. Rate Limiting & Abuse Prevention

### API Rate Limits
- **General:** Convex handles rate limiting at infrastructure level.
- **File Uploads:** Size limits on uploaded documents.
- **Template Limits:** Maximum 5 application templates per user.

### Content Limits
- **Bounties:** No limit on bounties per project.
- **Messages:** No artificial message limits.
- **Workspaces:** One workspace per project.

### Abuse Prevention
- **Admin Tools:** User suspension capability.
- **Project Moderation:** Admin can close inappropriate projects.
- **Certification Verification:** Manual review prevents fake credentials.
