# Part VII: Glossary of Terms

## Platform Terms

### VentureDeck
The name of this platform. Formerly known as "Launchpad" and "EchoinWhispr" during earlier development phases.

### Deal Flow
The dashboard and discovery interface where Investors browse, filter, and find potential investment opportunities. Similar to how VCs describe their incoming pipeline of deals.

### Project Forge (The Forge)
The wizard interface where Entrepreneurs create and publish their startup projects. Guides users through structured pitch documentation.

### Workspace
A collaborative team space automatically created for each project. Contains team members, chat channels, and shared resources.

### Living Pitch Deck
The concept of a project profile that evolves over time through milestone updates, rather than a static PDF document.

---

## User & Role Terms

### Entrepreneur
A platform user who creates and owns projects, seeking funding and team members. One of the two primary user roles.

### Investor
A platform user who discovers and evaluates investment opportunities. Can follow projects, express interest via soft circles, and access data rooms. The other primary user role.

### Builder (Talent)
Any user who applies to join project teams, typically developers, designers, or marketers seeking equity opportunities.

### Admin
A platform moderator with elevated privileges. Can verify certifications, moderate users/projects, and manage feature flags.

---

## Investment Terms

### Soft Circle
A non-binding expression of investment interest. Investors indicate an amount they're considering investing, helping founders gauge momentum without legal commitment.

### Traction Score
An AI-calculated score (0-100) that measures a project's momentum and completeness. Based on milestones, soft circles, followers, applications, team size, pitch deck, and legal documents.

### Score Breakdown
The component-by-component analysis of how a project's traction score was calculated. Helps founders understand what to improve.

### Data Room
A secure virtual room for sharing confidential due diligence documents with authorized investors. Includes access control and audit trails.

### Term Sheet
A non-binding document outlining the key terms of a proposed investment. One of the legal document templates available in VentureDeck.

### SAFE
Simple Agreement for Future Equity. A Y-Combinator-developed investment instrument where an investor provides capital in exchange for the right to future equity. A common legal template in VentureDeck.

### NDA
Non-Disclosure Agreement. A legal contract protecting confidential information shared between parties. Available as a template and optionally required for data room access.

### Convertible Note
A debt instrument that converts to equity upon a qualifying financing event. Available as a legal document template.

---

## Engagement Terms

### Milestone
A significant achievement or goal for a project (e.g., "MVP Launched", "First 100 Users"). Part of the Living Pitch Deck concept. Can be pending, completed, or verified.

### Bounty (Micro-Bounty)
A small task posted by a project with a defined reward (cash or equity). Allows founders to test talent before full team membership.

### Vouch
A public endorsement from one user to another, including relationship context (e.g., "Former Co-founder"). Builds reputation and trust.

### Certification
A professional credential (e.g., "AWS Solutions Architect") that can be submitted for admin verification. Verified certifications display a badge.

### Follow
The action of an investor subscribing to a project's updates. Followed projects appear in the investor's dashboard and generate activity notifications.

---

## Communication Terms

### Conversation
A chat thread between users. Types include: direct (1:1), workspace_general (team), interview (application-linked), and custom_chat.

### Interview Chat
A special conversation type linked to a job application, providing context for the hiring discussion.

### Channel
A named chat room within a workspace. Can be public (all workspace members) or private (invite-only).

### Notification
A platform message alerting users to events (new applications, messages, soft circles, etc.). Stored in the database and displayed in the notification panel.

### Activity Feed
A chronological stream of relevant events. Personal feeds show user-specific activity; discover feeds show platform-wide activity.

---

## Technical Terms

### Convex
The backend-as-a-service platform powering VentureDeck's database, serverless functions, and real-time capabilities.

### Clerk
The authentication provider handling user sign-up, sign-in, and identity management.

### Query
A Convex function that reads data from the database. Queries are reactive—UI automatically updates when underlying data changes.

### Mutation
A Convex function that modifies data in the database. Triggers immediately when called.

### Internal Mutation
A Convex function that can only be called by other server-side functions, not directly from the client. Used for background processing and scheduled jobs.

### Scheduled Function
A Convex function that runs on a timer (e.g., daily analytics snapshots). Configured via the Convex scheduler.

### Action
A Convex function that can perform side effects like calling external APIs. Used sparingly for integrations.

### HTTP Action
A Convex function that handles HTTP requests, typically used for webhook endpoints.

### Subscription
In Convex, a real-time connection that pushes data updates to the client automatically. In business terms, may refer to a paid plan (future feature).

### Storage ID
A unique identifier for a file stored in Convex File Storage. Used to retrieve and serve files securely.

### Feature Flag
An admin-controlled toggle that enables or disables specific platform features. Used for gradual rollouts and A/B testing.

---

## Analytics Terms

### Project Analytics
The dashboard showing project performance metrics over time—views, followers, applications, and traction score history.

### Daily Snapshot
An automated record of project metrics captured once per day. Powers historical trend charts.

### Unique Views
The count of distinct visitors who viewed a project, determined by user ID or browser fingerprint.

### Audit Trail
A log of access events for sensitive resources like data rooms. Records who accessed what and when.

---

## Matching Terms

### Matchmaking
The AI algorithm that recommends projects to investors based on their investment thesis (preferred industries, stages, check size, geography, score threshold).

### Match Explanation
A detailed breakdown of why a specific project was recommended to an investor, showing which criteria matched and each component's score contribution.

### Saved Search
A stored set of filter criteria that an investor can re-run quickly. Can optionally trigger alerts when new projects match.

### Investment Thesis
An investor's documented investment preferences including preferred industries, stages, geographic focus, and minimum traction score requirements.

---

## Application Terms

### Application
A request to join a project team, including the desired role and a cover message. Statuses: pending → interviewing → accepted/rejected.

### Application Template
A reusable message template that users can apply when submitting job applications. Speeds up the application process.

### Role
The position a user seeks or holds in a project (e.g., "Co-founder", "CTO", "Developer", "Marketing Lead").

---

## Legal Terms

### Legal Document Templates
Pre-formatted legal agreement templates with placeholder variables. Available types: SAFE, NDA, Advisor Agreement, Founder Agreement, Convertible Note, Term Sheet, Investment Agreement.

### Draft Status
A legal document that has been generated but not yet signed.

### Signed Status
A legal document that has been executed by the relevant parties.

---

## Friend System Terms

### Friend Request
An invitation to connect sent from one user to another. Can include an optional message.

### Friend
A mutual connection between two users after a friend request is accepted. Enables easy communication access.
