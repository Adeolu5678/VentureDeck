# Part III: Data Models & Database Schema

## 3.1. Database Schema Overview

The VentureDeck application uses Convex as its backend and database. The schema is defined in `Convex/convex/schema.ts` and contains **22 tables** organized into functional domains.

---

## 3.2. Core Entity Tables

### Users Table (`users`)

The central user table synchronized with Clerk authentication.

| Field | Type | Description |
|-------|------|-------------|
| `clerkId` | `string` | Unique identifier from Clerk (indexed). |
| `username` | `string` | Unique username for the platform. |
| `email` | `string` | Email address (indexed). |
| `firstName` | `string?` | First name (private). |
| `lastName` | `string?` | Last name (private). |
| `avatarUrl` | `string?` | Profile picture URL. |
| `avatarStorageId` | `string?` | Convex storage ID for uploaded avatar. |
| `role` | `"entrepreneur" \| "investor"?` | User's primary role (indexed). |
| `displayName` | `string?` | Public display name. |
| `professionalBio` | `string?` | Short professional biography. |
| `linkedinUrl` | `string?` | LinkedIn profile URL. |
| `githubUrl` | `string?` | GitHub profile URL. |
| `isVerified` | `boolean?` | Identity verification status. |
| `isAdmin` | `boolean?` | Administrator privileges. |
| `skills` | `string[]?` | List of professional skills. |
| `interests` | `string[]?` | List of interests. |
| `tags` | `string[]?` | Custom profile tags. |
| `investmentRange` | `{min, max}?` | Preferred investment range (investors). |
| `investorThesis` | `object?` | Detailed investor preferences (see below). |
| `notificationPreferences` | `object?` | Email/push preferences with digest settings. |
| `privacySettings` | `object?` | Profile visibility settings. |
| `needsUsernameSelection` | `boolean?` | Legacy onboarding flag. |
| `createdAt` | `number` | Creation timestamp. |
| `updatedAt` | `number` | Last update timestamp. |

**Investor Thesis Object:**
```typescript
{
  preferredIndustries: string[],     // e.g., ["Fintech", "AI"]
  preferredStages: string[],         // e.g., ["seed", "series-a"]
  thesisDescription: string,         // Investment thesis narrative
  geographicPreference: string,      // e.g., "North America"
  minTractionScore: number           // Minimum score threshold
}
```

**Indexes:** `by_clerk_id`, `by_email`, `by_role`, `search_username` (full-text)

---

### Projects Table (`projects`)

The core entity for Entrepreneur ventures.

| Field | Type | Description |
|-------|------|-------------|
| `ownerId` | `Id<"users">` | Creator/owner of the project (indexed). |
| `workspaceId` | `Id<"workspaces">?` | Linked workspace (set after creation). |
| `title` | `string` | Project name. |
| `tagline` | `string` | Short elevator pitch. |
| `description` | `string` | Full project description. |
| `industry` | `string` | Industry category (e.g., "Fintech"). |
| `tags` | `string[]?` | Custom project tags. |
| `fundingGoal` | `number` | Target funding amount in USD. |
| `equityOffered` | `number` | Percentage of equity offered. |
| `status` | `"draft" \| "published" \| "funded" \| "closed"` | Project lifecycle status. |
| `logoUrl` | `string?` | Project logo URL. |
| `pitchDeckUrl` | `string?` | URL to PDF pitch deck. |
| `stage` | `"idea" \| "mvp" \| "seed" \| "series-a" \| "series-b" \| "growth"?` | Funding stage. |
| `location` | `string?` | Geographic location for matching. |
| `tractionScore` | `number?` | AI-calculated traction score (0-100). |
| `scoreLastUpdated` | `number?` | Timestamp of last score calculation. |
| `scoreBreakdown` | `object?` | Component breakdown (see below). |
| `createdAt` | `number` | Creation timestamp. |
| `updatedAt` | `number` | Last update timestamp. |

**Score Breakdown Object:**
```typescript
{
  milestones: number,       // Points from milestone completion (0-20)
  softCircles: number,      // Points from investor commitments (0-20)
  followers: number,        // Points from follower count (0-15)
  applications: number,     // Points from job applications (0-15)
  teamCompleteness: number, // Points from team size (0-10)
  pitchDeck: number,        // Points for uploaded pitch deck (0-10)
  legalDocs: number         // Points for legal documents (0-10)
}
```

**Indexes:** `by_owner`, `by_status`, `by_industry_status`, `by_funding_status`, `by_traction_score`

## 3.4. Communication Tables

### Conversations Table (`conversations`)

| Field | Type | Description |
|-------|------|-------------|
| `participantIds` | `Id<"users">[]` | Users in the conversation. |
| `workspaceId` | `Id<"workspaces">?` | Parent workspace (if workspace chat). |
| `projectId` | `Id<"projects">?` | Related project (for context). |
| `applicationId` | `Id<"applications">?` | Related application (if interview). |
| `type` | `"direct" \| "workspace_general" \| "interview" \| "custom_chat"?` | Conversation type (indexed). |
| `name` | `string?` | Custom channel name. |
| `visibility` | `"public" \| "private"?` | Visibility within workspace. |
| `isClosed` | `boolean?` | Whether channel is archived. |
| `creatorId` | `Id<"users">?` | User who created the channel. |
| `archivedBy` | `Id<"users">[]?` | Users who have archived this chat. |

| `createdAt` | `number` | Creation timestamp. |
| `updatedAt` | `number` | Last activity timestamp. |

**Indexes:** `by_workspace`, `by_application`, `by_type`
