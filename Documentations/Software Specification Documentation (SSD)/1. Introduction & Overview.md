# Part I: Foundational Project Specification

## 1.1. Introduction and Document Purpose

This document is the definitive Software Specification Document (SSD) for the **VentureDeck** application. It serves as the single source of truth for all stakeholders, documenting the complete feature set as of December 2025.

VentureDeck is a premium platform connecting **Entrepreneurs** seeking funding with **Investors** looking for high-potential opportunities, and **Builders** (Talent) seeking to join early-stage teams. The platform provides structured tools for deal discovery, due diligence, team building, and relationship management.

## 1.3. User Personas

### Persona 1: The "Visionary" (Entrepreneur)
- **Description:** A startup founder with a promising idea seeking investment and team members.
- **Goal:** To structure their pitch, showcase traction, and connect with serious investors.
- **Pain Point:** Doesn't know how to structure a pitch or where to find serious investors.
- **Key Features Used:** Project Forge, Milestones, Bounties, Data Rooms, Analytics Dashboard.

### Persona 2: The "Angel" (Investor)
- **Description:** An accredited investor or VC scout looking for early-stage opportunities.
- **Goal:** To efficiently source and vet high-potential startups.
- **Pain Point:** Overwhelmed by low-quality inbound requests and lack of standardized data.
- **Key Features Used:** Deal Flow, AI Matchmaking, Saved Searches, Soft Circles, Data Room Access.

### Persona 3: The "Builder" (Talent)
- **Description:** A developer, designer, or marketer looking to join an early-stage team for equity.
- **Goal:** To find a project that matches their skills and passion.
- **Pain Point:** Difficulty finding legitimate opportunities and verifying team credibility.
- **Key Features Used:** Project Discovery, Applications, Application Templates, Bounties.

### Persona 4: The "Admin" (Platform Moderator)
- **Description:** A VentureDeck team member responsible for platform integrity.
- **Goal:** To maintain quality standards and verify certifications.
- **Pain Point:** Managing verification queue and handling policy violations.
- **Key Features Used:** Admin Dashboard, User Moderation, Certification Queue, Feature Flags.

## 1.4. User Journeys (Epics & Use Cases)

### Use Case 1: Project & Workspace Creation
- **Actor:** Entrepreneur.
- **Trigger:** User clicks "Start New Project."
- **Steps:**
  1. User enters Project Essentials (Name, Tagline, Industry, Logo).
  2. User defines The Pitch (Description, Problem, Solution).
  3. User sets The Ask (Funding Goal, Equity Offered, Stage).
  4. User publishes the project.
  5. **System automatically creates a Workspace** with the Entrepreneur as owner.
- **Post-condition:** Project is live on the marketplace, and a collaborative workspace is ready.

### Use Case 2: Certification Verification
- **Actor:** Entrepreneur / Talent.
- **Trigger:** User uploads a certification image.
- **Steps:**
  1. User submits certification details (title, proof image).
  2. System creates pending certification record.
  3. Admin reviews the submission in the Certification Queue.
  4. Admin approves or rejects with optional notes.
- **Post-condition:** A "Verified" badge appears next to the cert on the user's profile.

### Use Case 3: Deal Discovery & Filtering
- **Actor:** Investor.
- **Trigger:** User visits the "Deal Flow" dashboard.
- **Steps:**
  1. User filters by Industry, Stage, Funding Goal, or Traction Score.
  2. System displays matching projects sorted by relevance.
  3. User can save the search for future use with optional alerts.
  4. User clicks a project to view the full pitch and traction data.
- **Post-condition:** Investor has detailed project information with AI-calculated match scores.

### Use Case 4: Connection & Negotiation
- **Actor:** Investor.
- **Trigger:** User clicks "Contact Founder" on a project.
- **Steps:**
  1. A private conversation channel is created.
  2. Investor and Founder discuss terms via real-time messaging.
  3. Investor can express interest via "Soft Circle" commitment.
- **Post-condition:** Direct line of communication established with commitment tracking.

### Use Case 5: Team Application & Interview
- **Actor:** Talent (Builder).
- **Trigger:** User clicks "Apply to Join" on a project.
- **Steps:**
  1. User selects an application template or writes custom message.
  2. User submits profile and note for the desired role.
  3. Founder receives notification and reviews application.
  4. Founder starts an "Interview Chat" to verify skills.
  5. Founder accepts application.
- **Post-condition:** User is added to the project workspace with appropriate role.

### Use Case 6: AI-Powered Matchmaking
- **Actor:** Investor.
- **Trigger:** User views "Recommended for You" section.
- **Steps:**
  1. System analyzes investor's thesis (industries, stages, check size).
  2. Algorithm scores all published projects against investor profile.
  3. Top matches are displayed with explanation of match factors.
  4. User can click to see detailed match breakdown.
- **Post-condition:** Investor discovers relevant opportunities without manual filtering.

### Use Case 7: Due Diligence Data Room
- **Actor:** Entrepreneur (Creator) / Investor (Viewer).
- **Trigger:** Founder creates a Data Room for their project.
- **Steps:**
  1. Founder creates Data Room with access type (invite-only or NDA-required).
  2. Founder uploads confidential documents (financials, contracts).
  3. Founder grants access to specific investors.
  4. Investor views documents (system logs access for audit trail).
  5. Founder can revoke access at any time.
- **Post-condition:** Secure document sharing with full audit trail.

### Use Case 8: Legal Document Generation
- **Actor:** Entrepreneur.
- **Trigger:** User needs a legal document for their project.
- **Steps:**
  1. User selects document type (SAFE, NDA, Advisor Agreement, etc.).
  2. System loads template with placeholder variables.
  3. User fills in project-specific and party-specific details.
  4. System generates formatted document.
  5. Document is stored in project's legal documents section.
- **Post-condition:** Professional legal document ready for review and signing.

### Use Case 9: Project Analytics
- **Actor:** Entrepreneur.
- **Trigger:** User views their project's Analytics page.
- **Steps:**
  1. System displays real-time metrics (views, followers, applications).
  2. Historical trends shown via charts (daily snapshots).
  3. Traction score displayed with component breakdown.
  4. User can identify which metrics to improve.
- **Post-condition:** Data-driven insights for improving project visibility.

### Use Case 10: Admin Moderation
- **Actor:** Admin.
- **Trigger:** Admin accesses moderation dashboard.
- **Steps:**
  1. Admin views pending certifications for verification.
  2. Admin can search/filter users and projects.
  3. Admin can suspend users or change project status.
  4. Admin manages feature flags to control platform features.
- **Post-condition:** Platform quality and policy enforcement maintained.

## 1.5. Project Scope

### In Scope (Implemented Features)

#### Core Platform (MVP)
- **Dual-Role Authentication:** Entrepreneur / Investor roles with Clerk integration.
- **Project Creation Wizard ("The Forge"):** Structured project creation with auto-workspace.
- **Project Marketplace:** Advanced filtering by industry, stage, funding, tags.
- **Team Application System:** Applications with interview chats and role assignments.
- **Direct Messaging:** Real-time chat for Investor-Founder, Team, and Custom channels.
- **User Profiles:** Verified certifications, professional bio, skills, and interests.
- **Workspace Collaboration:** Team chat, member management, and role assignments.

#### Advanced Features (Phase 2 - Implemented)
- **Living Pitch Decks:** Milestone system with completion and verification tracking.
- **Micro-Bounties:** Task posting with claim, submission, review, and payment workflow.
- **AI Deal Scoring:** Automatic traction score calculation with weighted components.
- **AI Matchmaking:** Investor-Project matching with detailed explanations.
- **Soft Circle Commitments:** Non-binding investment interest with status tracking.
- **Project Followers:** Investors can follow projects for updates.
- **Due Diligence Data Rooms:** Secure document sharing with access control and audit trails.
- **Legal Document Templates:** SAFE, NDA, Advisor Agreement, Founder Agreement, Convertible Note, Term Sheet, Investment Agreement.
- **Saved Searches:** Filter persistence with optional new-match alerts.
- **Application Templates:** Reusable application messages for faster applying.
- **Project Analytics:** View tracking, daily snapshots, and trend visualization.
- **Vouched Reputation:** Users can vouch for others with relationship context.
- **Activity Feed:** Personal and platform-wide activity streams.
- **Friends System:** Connection requests and friend management.
- **Notifications:** Platform-wide notification system with multiple types.
- **Feature Flags:** Admin-controlled feature toggles.
- **Admin Dashboard:** User moderation, project moderation, certification queue.

### Out of Scope (Future Iterations)
- **In-app Payment Processing:** Direct investment transactions (regulatory complexity).
- **DAO Governance:** Decentralized decision-making structures.
- **On-chain Equity Management:** Smart contract-based cap table management.
- **AI Analyst:** Automated due diligence report generation.
- **Email Notification Delivery:** Currently placeholder ("Coming Soon").
- **Push Notifications:** Mobile push notification infrastructure.

## 1.6. Platform Architecture

### Client Applications
- **Web Application:** Next.js 15 with App Router, hosted on Vercel.
- **Mobile Application:** Flutter (in development), targeting iOS and Android.

### Backend Services
- **Database & API:** Convex (real-time, serverless).
- **Authentication:** Clerk (multi-role sessions, webhooks).
- **File Storage:** Convex File Storage (pitch decks, legal docs, avatars).

### External Integrations
- **Stripe:** Planned for premium features and bounty payments.
- **Google Fonts:** Sora and Outfit typography.
